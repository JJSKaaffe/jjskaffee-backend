## Hoja: Plantilla Visión

| Cliente/público objetivo del nuevo producto: | El publico objetivo de nuestro proyecto son las cafeterias pequeñas y medianas |
|---|---|
| Necesidad del cliente/público y/o oportunidad: | Se necesita tener un registro contable |
| Nombre del nuevo producto: | JJSkafee |
| Tipo de producto: | Es una plataforma web para computadores |
| Principal beneficio o razón del nuevo producto: | Permite al administrador de la cafeteria tomar decisiones financieras en base a reportes y seguimiento de los movimientos economicos |
| Aplicaciones ya existentes y/o situación actual: | Siigo, Vendty, Loggro |
| Principal diferenciación del nuevo producto: | Nuestro producto ofrece un servicio que tenga personalizacion por parte del administrador, ademas de comparaciones de movimientos actuales con movimientos pasados y si pasan ciertos eventos que el administrador decide el sistema mandara una alerta |
| Visión |  |
| Para las cafeterías y sus administradores que necesitarán llevar un control eficiente de sus ingresos y egresos y mejorar la toma de decisiones financieras, JJSCoffee será un sistema web de gestión financiera que permitirá registrar, organizar y consultar la información económica del negocio de forma rápida y segura. A diferencia de los registros manuales o las hojas de cálculo, nuestro producto ofrecerá un control centralizado, reportes automáticos y acceso a la información en tiempo real. |  |
